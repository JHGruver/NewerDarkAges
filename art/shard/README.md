# Shard Cel art (MVP edition)

Drop new art here. The site finds it on its own, no wiring needed.

- Portrait: `<id>.png` (3:4, transparent, about 1050 x 1400)
- Background: `<id>-bg.jpg` (16:9, about 1600 x 900)

`<id>` is the character id, for example `fuelpriests.png` and `fuelpriests-bg.jpg`. The ids are listed in the Prompt interface (#/prompts) under each character.
Each file replaces the older art for that character in the MVP edition as soon as it is pushed.
